Calculate Linen Par Stock from Your Laundry Cycle

Estimate sheet and towel sets from installed beds, changeovers, laundry turnaround, spares, and clean storage capacity.

Updated October 6, 2026

Linen par stock is the quantity needed to keep the property supplied while used items are being washed or held aside. A fixed rule of “three sets” may be a useful starting thought, but the right quantity depends on the laundry process, turnover pattern, losses, and storage available at this property.

Make the decision from the actual setup

Define one set precisely before doing arithmetic. For a bed, specify sheet sizes, pillowcase quantity, and any cover included in the reset. Towels need a separate calculation based on the actual supplied allocation. Count the sets installed, the sets required for upcoming resets before laundry returns, and a separately stated spare allowance.

Map collection and return times with the laundry provider. Clean stock must be ready before it is needed, not merely expected back later that afternoon. Do not treat dirty, stained, incompatible, or damp items as available sets. Check storage size and handling so extra stock can remain clean, dry, and identifiable.

Worked planning example

Illustrative scenario: Examples, prices, quantities, and timing assumptions below are hypothetical; use actual product information and local quotes for your property.

Hypothetical sheet plan: three beds each need one installed set, totaling three. The laundry process can leave one full changeover of three sets away at once. One additional set per bed is held as an assumed contingency, adding three. The total is nine complete sets. If two changeovers can occur before returns, the working stock changes: three installed plus six away plus three spare equals twelve. These quantities illustrate the method rather than prescribing stock for every rental.

Practical checklist

  1. Define a complete set by bed size and actual reset specification, including pillowcases and covers where supplied.
  2. Map the laundry collection, processing, return, and storage cycle against possible changeover timing.
  3. Calculate installed stock, working-cycle stock, and contingency separately so each assumption is visible.
  4. Exclude unsuitable, incomplete, damp, or damaged items from the available clean count.
  5. Check storage capacity and label sets so the cleaner can quickly select the correct size and version.

Carry the decision into the handover

Reconcile physical stock regularly and record losses or repeated shortages by item. If pillowcases disappear faster than sheets, buy the missing component rather than automatically purchasing whole sets. Adjust the assumed contingency from actual experience. A larger par quantity cannot solve unreliable returns or inadequate drying; fix the process as well as the count.
