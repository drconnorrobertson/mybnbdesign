A room-by-room punch list for rental furnishing installation

Installation is complete when the property is ready for its intended use, not when the truck leaves. Keep a punch list that records unresolved fit, condition, assembly and inventory issues with a responsible person and a close date.

Check against the approved plan · Test the guest setup · Record evidence and ownership · Reinspect before closing · Worksheet

Check against the approved plan

Walk each room with the furniture list and latest layout. Confirm models, colors and quantities, then inspect condition. Separate missing goods from assembly issues and design changes so each item reaches the person able to resolve it.

Test the guest setup

Open drawers and doors, extend tables and unfold any convertible furniture as instructed. Check how guests reach controls, charging points and storage. Review the arrangement in daytime and evening lighting. Refer installation or safety concerns to the qualified person responsible rather than improvising a fix.

Record evidence and ownership

Use one record per issue with a photograph, room, description and required action. Assign a named owner and priority based on whether the issue prevents intended use. A decorative adjustment and an unusable bed should not be treated as the same completion category.

Reinspect before closing

Require evidence that the action has actually been completed. Revisit related functions after a repair or replacement. Only then update the care inventory, final room photographs and handover documents. Keep open items visible to the person deciding readiness.

A worked planning scenario

A hypothetical installation arrives with the correct dining table and chairs, but a drawer unit prevents a bedroom door from opening fully. The punch list identifies a layout problem, assigns the designer to revise placement and requires an updated room photo before closure.
