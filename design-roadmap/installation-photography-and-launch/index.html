Install, test and photograph the real property

Installation completion, photographic readiness and guest readiness are related but separate checks. Use evidence from the installed rooms before publishing the listing.

Updated October 13, 2026

Stage 10 of 12. See the full curriculum and choose your starting stage

The decision to make

Compare delivered goods with the approved layout and inventory. Keep instructions and installation records for the exact products. Test doors, drawers, convertible furniture, lighting controls and storage in normal use. Send mounting, electrical, plumbing and other specialist concerns to the qualified person responsible. Record missing items and temporary arrangements explicitly.

How to carry it out

Create a punch list with one issue per record, a room identifier, evidence, action owner and reinspection. Prioritize issues that prevent intended use. Before photography, complete the cleaning and styling reset and agree on a truthful shot list. Images should represent the amenities and layout guests will receive. Track selected image files and which channels use them so later changes trigger the necessary updates.

Worked planning example

Illustrative scenario; not a client case or performance result.

A hypothetical bedroom is styled while a temporary lamp substitutes for the approved fixture. The punch list records the substitution and the photographer is told whether to postpone that room. The owner does not publish a staged amenity that will be removed before the first guest arrives.

Decision gate: evidence before moving on

Accept launch readiness when the intended-use checks pass, essential issues are resolved and the photographed inventory matches the operating property. Preserve the final record and local handover.

Build the working record

Use one record per property and decision. Replace the prompts with verified information, retain the source documents and mark anything that still requires confirmation. Assign a person and a date to open questions instead of leaving them buried in conversation.

Use the record with your project team

Start with the current approved revision. Send the same document to the owner, designer and local coordinator so each person can see which decisions are settled. Keep quotes and manufacturer information attached to the relevant line. When a decision changes, record what changed, why it changed and which downstream documents must be updated.

At the next review, compare the installed or contracted result with the recorded requirement. Close an item only when the required evidence exists. If the record describes a planned purchase, do not relabel it as installed inventory until receiving and site checks confirm it. If the property is already operating, schedule work around the actual calendar and communicate the affected rooms and amenities to the person responsible for listing accuracy.
