How to use an example

Replace the hypothetical assumptions with actual room dimensions, retained furniture, intended guests and operating constraints. Test the proposed decision through guest use and turnover before choosing products. Compare the same finished condition in each proposal, then keep the accepted plan and product records together.

For evidence of a completed assignment, request project-specific documentation and a clear explanation of the design team’s role. A hypothetical example should never be used as proof of past financial performance.
