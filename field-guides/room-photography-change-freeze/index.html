Design and installation · Field guide · October 9, 2026

Set a room photography change freeze

A photography freeze defines which room version is being represented in the listing images. Record the approved setup, outstanding substitutions and any temporary items. The freeze helps design and management coordinate the shoot; it does not justify showing features that will not be available to guests.

Work through the decision

  1. Agree the room version for the shoot.
  2. Remove or disclose temporary staging internally.
  3. Record changes after photography.
  4. Review whether listing images need updating.

For each action, name the person responsible for preparing the response and the person who approves it. Record what evidence would close the item. If new information changes cost, timing or scope, update the affected plan and identify who needs the revised version.

Common failure to avoid

A photograph can remain attractive while becoming inaccurate. Review changes to sleeping arrangements, amenities and major furniture after the shoot.

Worked example

In an illustrative project, an accent chair is borrowed for staging but is not part of the guest inventory. The team replaces it with the actual item before photography rather than making the listing depend on a temporary setup.

This is an illustrative workflow, not a client case study or a forecast. Replace the example’s facts with the records for your own project.

Close the handoff

A finished worksheet should identify the result, its evidence and any remaining owner. If the result is uncertain, record the next action instead of marking the whole task complete. Keep the worksheet with the relevant source file and tell the receiving person which version applies.
