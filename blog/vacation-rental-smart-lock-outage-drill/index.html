Run a smart-lock outage drill before the first stay

Check whether the local team can restore entry without relying on the usual app or Internet connection.

Worked example

The guest reaches the door, but the remote operator cannot reach the lock through its app. Ask the on-site contact to use the actual backup method in the property’s operating plan while a teammate reads the guest instructions.

What to test and document

Run the test without sharing live codes in the report. Record which components depend on connection or power, who can respond locally and how long the backup took.
