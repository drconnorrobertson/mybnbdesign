Check door alignment before installing a vacation rental keypad

Make sure the existing door closes and locks comfortably before choosing or installing hardware.

Worked example

A deadbolt moves freely when the door is open but catches when closed. Show that difference to the installer before adding a keypad and record the doors or weather conditions affected.

What to test and document

Photograph both sides and the edge of the door. Ask the installer to check alignment and confirm compatibility in person if needed, then have an unfamiliar user test the finished door from outside.
